<h1>Kerberoasting Attack & Defense</h1>

<h2>Description</h2>

This phase documents the simulation, investigation, and defense of a controlled Kerberoasting attack within an Active Directory environment. The goal of this phase is to understand how Kerberoasting targets Kerberos service accounts, identify evidence generated by the attack, and implement defensive measures to reduce the associated security risk. A Kali Linux virtual machine will be used as the attacker system to identify Kerberoastable service accounts, request Kerberos service tickets, and demonstrate the security risks associated with weak service account credentials.

<br />In this phase, the following topics will be covered:
- <b>Kerberos authentication</b>
- <b>Service Principal Names (SPNs)</b>
- <b>Service accounts</b>
- <b>Kali Linux attacker environment</b>
- <b>Kerberoasting attack simulation</b>
- <b>Offline password cracking</b>
- <b>Windows security event analysis</b>
- <b>Attack investigation</b>
- <b>Service account hardening</b>
- <b>Mitigation and remediation</b>
- <b>Post-remediation verification</b>

This phase provides hands-on experience with understanding, investigating, and defending against Kerberoasting within an Active Directory environment.
